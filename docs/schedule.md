# 17-Week Development Schedule

| Weeks | Work |
| --- | --- |
| 1-4 | Requirements research, FSSAI source review, benchmark preparation |
| 5-8 | Claim extraction, normalization, ontology integration |
| 9-12 | Versioned rule engine, comparator resolution, evidence model |
| 13-15 | Website, PWA, backend integration, security hardening |
| 16 | Benchmark evaluation, baseline comparison, error analysis |
| 17 | Deployment, documentation, demonstration, final audit |

## Team division

Member 1 can lead image/product data processing, claim extraction, normalization, and benchmark preparation. Member 2 can lead the rule engine, comparator resolution, evidence model, backend, and hosted platform. Both members share integration, evaluation, and testing. Team member names remain configurable and are intentionally not invented here.
